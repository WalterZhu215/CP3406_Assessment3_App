# Nature Explorer

## CP3406 - Assessment 3

### Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Design System:** Material Design 3

### Ethical Frameworks & Compliance (Assessment 2 Integration)
This application strictly adheres to the ethical frameworks and principles analyzed in Assessment 2, ensuring responsible software development:

* **The Privacy-Innovation Paradox:** We balance the innovative features of a nature exploration app with stringent user data protection. Data collection is transparent and strictly purposeful.
* **Principle of Least Privilege:** The application is engineered to request only the absolute minimum permissions required for core functionality (e.g., requesting coarse location instead of precise location where applicable), minimizing potential attack vectors and respecting user autonomy.
